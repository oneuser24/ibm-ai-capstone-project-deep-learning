# Labs for the IBM 'AI Capstone Project with Deep Learning' on Coursera

In this project, deep learning techniques are applied to solve a real-world geospatial image classification problem. Keras and PyTorch are used to develop, train, and evaluate convolutional neural networks (CNNs) and vision transformers. It helps in gaining hands-on experience in model optimization, performance analysis, and technical reporting.

## Project scenario

AI Engineer working at a fertilizer company tasked with building a land classification system for agricultural applications. Using satellite imagery, the goal is to develop models that can accurately classify different types of terrain (e.g., crops, forests, water bodies). This project will involve:

* Data preprocessing: Loading and augmenting geospatial image datasets
* Model development: Designing CNNs and vision transformers in Keras and PyTorch
* Transfer learning: Fine-tuning pre-trained models for improved accuracy
* Performance evaluation: Comparing models using metrics like accuracy, F1-score, and AU-ROC
* Technical reporting: Documenting your methodology, results, and insights in a final project report
